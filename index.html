游戏概览

这是一款基于 Three.js 的 3D 第一人称钓鱼游戏，支持 PC 与手机，支持多人联机同屏。

你出生在海岛中央的草地上，面朝大海。核心循环非常简单：

抛竿瞄准水面右键
→
等待鱼漂入水
→
咬钩准星变红
→
收线获得鱼获
→
卖钱升级鱼竿

游戏会自动存档（本地 localStorage），关掉网页再打开也能接着玩。联机部分使用公共 MQTT 服务器，所有人默认在同一个房间。

世界构成

中央海岛（草地＋沙滩）四周环海，海面有实时波浪，水下会自动切换蓝色滤镜。海床深度约 15 单位。

多人联机

其他玩家的位置、朝向、名字、皮肤、鱼漂与鱼线都会实时同步，还带聊天频道。

自动存档

每 5 秒自动保存一次，关闭页面前也会保存。金钱、背包、等级、设置、位置全部保留。

钓鱼机制详解

理解这四步，你就掌握了这款游戏的全部核心。

① 抛竿

按下抛竿键后，系统会从屏幕正中央发出一条射线，与水面（y = 0）求交，落点就是鱼漂位置。

  • 最远抛竿距离：30 单位，超出会自动截断
  • 鱼漂会沿抛物线飞出，飞行约 0.4 秒
  • 落点在陆地上时，鱼漂会停在陆地表面
关键陷阱：如果鱼漂落在陆地上，永远不会咬钩！游戏会一直卡在等待状态，直到你手动收线。抛竿前请务必对准水面。

② 等待

鱼漂入水后会上下浮动，等待时间由鱼竿等级决定（见「鱼竿升级」章节）。每竿额外有 ±1 秒的随机浮动，避免节奏过于机械。

③ 咬钩

鱼咬钩时会出现明显提示：

  • 屏幕中央准星变红并跳动
  • 鱼漂下沉并剧烈摇晃
  • 鱼竿呈后拉姿态
限时 2 秒！咬钩后 2 秒内没有收线，鱼就会跑掉，需要重新等待一轮，并提示「鱼跑了，继续等待…」。

④ 收线与收获

在咬钩窗口内收线即可获得鱼获，屏幕上会弹出 +1 鱼名 的漂浮提示。

  • 每次必定获得 1 条鱼（按权重随机）
  • 额外有 75% 概率再获得 1 只虾（售价 ￥1）
  • 新钓到的鱼默认是「生鱼」状态

鱼竿升级

鱼竿等级决定了「等待咬钩的时间」，等级越高收益越快。在商店里点「升级」按钮购买。

经济系统 · 商店

按 B 或点击左上角购物车图标打开商店。

卖鱼

  • 点击左侧「背包」里的鱼即可选中（青色边框）
  • 点击卡片上的「卖出」按钮，立即获得对应金币
  • 只能卖生鱼，烤熟的鱼不可出售
  • 背包为空时会提示「背包为空，去钓鱼吧！」

烤鱼与食用

  • 先在左侧选中一条生鱼
  • 点击右侧「烤制选中的鱼（花费 ￥5）」
  • 烤熟后卡片按钮变为绿色的「食用 (+20)」
  • 食用后回复 20 点饥饿值，鱼消失

经济策略建议

  • 前期优先卖鲩鱼（￥20）、章鱼（￥25）、草鱼（￥15）攒钱升级鱼竿
  • 饥饿值低于 30 时再考虑烤鱼，不要用高价鱼烤——一条鲩鱼能卖 20 元，烤了只回 20 饥饿
  • 用虾、金鱼、鲍鱼这类低价鱼去烤最划算
  • 鱼竿等级越高，单位时间收入提升越明显，前中期优先升级

  • ■ 60 ~ 100：蓝色（正常）
  • ■ 30 ~ 59：橙色（注意）
  • ■ 0 ~ 29：红色（危险）

饿死惩罚

  • 屏幕闪红，饥饿值重置为 100
  • 鱼竿等级 -1（最低降到 1 级）
  • 若已是 1 级，不扣等级但仍会重置饥饿
  • 正在进行的钓鱼会被强制中断

  • 自定义皮肤贴图

聊天

  • PC：T / Enter 打开输入框，Enter 发送，Esc 取消
  • 手机：点右下角「聊」按钮，弹出输入面板
  • 单条消息最多 50 字
  • 屏幕上最多同时显示 5 条，5 秒后自动淡出
注意：游戏使用的是公共 MQTT 服务器和固定房间号，理论上陌生人也能进入同一房间。 聊天内容和皮肤会广播给房间内所有人，请不要发送敏感信息，也不要使用来源不明的图片作为皮肤。

设置项详解

按 Esc 或点击左上角 ☰ 打开设置面板。

名
玩家名字

显示在自己和其他玩家头顶。默认为随机生成的 64 位字母数字串，修改后最多保留 20 个字符，清空则显示为「无名氏」。

皮
关联本地皮肤文件

使用浏览器的 File System Access API，选择一个本地图片作为角色圆柱体的贴图。路径会被记住，下次打开自动加载（只要文件没被移动或重命名）。图片会自动压缩到最长边 256px。需要 Chrome / Edge 等支持该 API 的浏览器。

触
触屏模式（0 关 / 1 开）

开启后显示虚拟摇杆和动作按钮，隐藏准星；关闭则使用鼠标锁定视角。会自动根据设备初始化。

圈
光圈基础大小（20 ~ 150）

触屏模式下点击画面时出现的反馈光圈直径，默认 60px。

草
显示草地（0 关 / 1 开）

控制岛上 3000 丛草的显示。关闭可显著提升低端设备的帧率。

浪
海面波浪（0 关 / 1 开）

控制海面顶点的实时波动与法线重算。这是本作最消耗性能的选项，卡顿时优先关闭它。

敏
摄像机灵敏度（10 ~ 200）

影响鼠标与触屏拖动的转视角速度，默认 100。

准
准星样式

1 = 十字「+」；2 = 白色圆点（默认）；3 = 自定义字符。咬钩时准星会变红跳动。

字
自定义准星

输入最多 2 个字符作为准星，输入后准星样式会自动切换到「3」。

存档与皮肤存储

游戏存档

  • 存储位置：浏览器 localStorage
  • 键名：fishing_save
  • 保存内容：金钱、饥饿、鱼竿等级、背包、所有设置、位置与视角
  • 自动保存：每 5 秒 + 关闭页面前

皮肤句柄

  • 存储位置：浏览器 IndexedDB
  • 数据库名：FishingGameDB
  • 只保存文件的「句柄」，不复制文件本身
  • 文件被移动 / 删除后会回退到默认黑色圆柱体
重置存档：打开浏览器控制台执行 localStorage.removeItem('fishing_save') 后刷新页面即可从头开始。

技巧与冷知识

实用技巧

  • 永远瞄准水面：抛到陆地 = 永久卡住，必须手动收线重抛
  • 准星对准远处能抛更远，但超过 30 单位会被截断
  • 水中移动更慢（速度 4 对比陆地 7.5），但冲刺仍然翻倍
  • 水中按空格可以不断上浮，不会沉下去
  • 烤鱼用便宜鱼：虾（￥1）、金鱼（￥5）、鲍鱼（￥5）最适合当口粮
  • 满级鱼竿等待只要 1~2 秒，配合卖鱼几乎可以无限刷钱
  • 卡顿时优先关掉海面波浪，其次关掉草地

冷知识

  • 饿死只掉 1 级鱼竿，但饥饿值会回满，所以后期掉级影响有限
  • 熟鱼不能卖，只能吃，别把大肥鱼给烤了
  • 默认玩家名由 39 个随机字母 + 25 个随机数字组成，共 64 位
  • 其他玩家的角色是一个圆柱体，名字是画在 Canvas 上的贴图
  • 鱼线是实时计算的二次贝塞尔曲线，从鱼竿尖端连到鱼漂
  • 水下时整个屏幕会叠加一层蓝色滤镜
  • 设置里的「灵敏度」在 PC 与触屏使用不同的换算系数
  • 关闭海面波浪时，水面会被强制压平成 y = 0 的平面

常见问题 FAQ

为什么我抛竿后一直没鱼咬钩？

大概率是鱼漂落在了陆地上。只有落在水面的鱼漂才会触发咬钩判定。按收线键收回重新抛一次，注意把准星压到水面上。

为什么看不见其他玩家？

联机依赖公共 MQTT 服务器，可能因为网络环境、防火墙或服务器繁忙导致连接失败。打开浏览器控制台查看是否输出「MQTT 已连接」。另外，其他玩家需要先广播一次才会被创建，通常几秒内就能看到。

皮肤选了却没生效？

需要浏览器支持 File System Access API（Chrome / Edge 89+）。另外文件被移动、重命名或删除后，下次打开会回退到默认黑色圆柱体，重新选一次即可。Safari 与部分移动端浏览器不支持该功能。

游戏卡顿怎么办？

按 Esc 打开设置，把「海面波浪」和「显示草地」都设为 0。这两个是性能大户，关闭后帧率通常有明显提升。

换了浏览器存档还在吗？

不在。存档保存在当前浏览器的 localStorage 中，换浏览器、换设备、清除浏览器数据都会丢失。皮肤句柄同样只存在于当前浏览器的 IndexedDB 中。

满级之后还能做什么？

满级（10 级）后升级按钮会隐藏。剩下的目标就是：收集满背包、钓到那条 0.036% 的大肥鱼、和房间里的玩家聊天，或者换个皮肤继续钓鱼。
